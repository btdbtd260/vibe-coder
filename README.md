# Vibe Coder

An idle/incremental "coding" game built with React 19, TypeScript, Vite, and TailwindCSS 4.

Write code, earn money, level up, ascend, and work your way from Junior Dev to Framework Architect.

## Development

```bash
npm install
npm run dev
```

## Testing

```bash
npm test
```

## Build

```bash
npm run build
```

## Tech Stack

- **React 19** — UI framework
- **TypeScript** — type safety
- **Vite** — bundler
- **TailwindCSS 4** — styling
- **Vitest** — testing
- **Motion** — animations
